# KubeCA Operator API

Status: proposed, `kubeca.effectivesecurity/v1alpha1` (D-1). Go types
go to `api/v1alpha1/` with kubebuilder markers; CRDs are generated by
`controller-gen` into `config/crd/bases/` and copied to
`examples/kubeca/crds/`. Architecture: [operator.md](operator.md).

Naming rules: labels and annotations use the group as prefix; condition
types are `Ready` and `Issuing`; reasons are CamelCase and listed below;
Secret keys follow `kubernetes.io/tls` plus `ca.crt`.

## ClusterIssuer

Cluster-scoped. Binds an xpki issuer (loaded from the CA configuration at
start-up) to a policy and publishes its CA.

```yaml
apiVersion: kubeca.effectivesecurity/v1alpha1
kind: ClusterIssuer
metadata:
  name: kubeca
spec:
  # Issuer label in ca-config (authority.issuers[].label). Required.
  issuerLabel: kubeca.svc
  # Profiles this ClusterIssuer exposes. Empty: every profile the issuer serves.
  profiles: [peer-24h, server-24h, client-24h]
  # Used when a Certificate omits spec.profile.
  defaultProfile: peer-24h
  spiffe:
    # Pod-flow URIs: spiffe://<trustDomain>/ns/<namespace>/sa/<serviceaccount>
    trustDomain: example.org
  policy:
    # Namespaces whose Certificates may use this issuer. Absent: all.
    namespaceSelector:
      matchLabels:
        kubeca.effectivesecurity/enabled: "true"
    # Upper bound for Certificate.spec.duration; also bounded by the profile expiry.
    maxDuration: 24h
    # Regexes; ${NAMESPACE}, ${NAME}, ${SERVICE_ACCOUNT} are substituted (regex-quoted).
    allowedDNSNames:
      - ^[a-z0-9-]+\.${NAMESPACE}\.svc(\.cluster\.local)?$
      - ^[a-z0-9-]+\.[a-z0-9-]+\.${NAMESPACE}\.svc(\.cluster\.local)?$
      # one wildcard label over a headless Service (StatefulSet Pod names)
      - ^\*\.[a-z0-9-]+\.${NAMESPACE}\.svc(\.cluster\.local)?$
      - ^[0-9-]+\.${NAMESPACE}\.pod\.cluster\.local$
      - ^localhost$
    allowedURIs:
      - ^spiffe://example\.org/ns/${NAMESPACE}/sa/[a-z0-9-]+$
    allowedEmailAddresses: []
    allowIPAddresses: true
  caBundle:
    # Optional: publish ca.crt into this ConfigMap in every namespace that has a Certificate of this issuer.
    configMapName: kubeca-ca
status:
  conditions:
    - type: Ready
      status: "True"
      reason: Loaded
      message: issuer kubeca.svc, 3 profiles
      lastTransitionTime: "2026-10-06T10:00:00Z"
      observedGeneration: 1
  issuerKeyID: 5A:3F:... # SKID of the issuing certificate
  caCertificate: | # issuing certificate + chain, PEM
    -----BEGIN CERTIFICATE-----
  rootCertificate: | # root bundle, PEM (what goes into ca.crt)
    -----BEGIN CERTIFICATE-----
  caNotAfter: "2031-10-06T00:00:00Z"
  profiles:
    - name: peer-24h
      expiry: 24h
      backdate: 5m
      usages: [signing, key encipherment, server auth, client auth]
```

| Field                                                                 | Type                 | Validation                          | Notes                                                                                                                                                                                                                |
| --------------------------------------------------------------------- | -------------------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `spec.issuerLabel`                                                    | string               | required, immutable                 | Must exist in the running Authority; otherwise `Ready=False/IssuerNotFound`                                                                                                                                          |
| `spec.profiles`                                                       | []string             | each must be served by the issuer   | Unknown entries → `Ready=False/ProfileNotFound`                                                                                                                                                                      |
| `spec.defaultProfile`                                                 | string               | must be in `profiles` when both set |                                                                                                                                                                                                                      |
| `spec.spiffe.trustDomain`                                             | string               | DNS name                            | Enables the SPIFFE URI in the Pod flow                                                                                                                                                                               |
| `spec.policy.namespaceSelector`                                       | metav1.LabelSelector |                                     | nil = all namespaces                                                                                                                                                                                                 |
| `spec.policy.maxDuration`                                             | metav1.Duration      | > 0                                 |                                                                                                                                                                                                                      |
| `spec.policy.allowedDNSNames`, `allowedURIs`, `allowedEmailAddresses` | \*[]string           | valid RE2 after substitution        | Empty list = that name type is denied; absent = allowed (a pointer in Go, so a client's explicit `[]` is not dropped by `omitempty`). A wildcard name is allowed only by an expression that matches the leading `*.` |
| `spec.policy.allowIPAddresses`                                        | bool                 |                                     | default false                                                                                                                                                                                                        |
| `spec.caBundle.configMapName`                                         | string               | DNS-1123 label                      | Phase P7                                                                                                                                                                                                             |

Conditions: `Ready` with reasons `Loaded`, `IssuerNotFound`,
`ProfileNotFound`, `CAExpiring` (CA `NotAfter` < now + `maxDuration`),
`CAExpired`.

Printer columns: `READY`, `LABEL` (`spec.issuerLabel`), `CA NOT AFTER`,
`AGE`. Short name: `cissuer`.

## Certificate

Namespaced. Describes one certificate and the Secret that holds it.

```yaml
apiVersion: kubeca.effectivesecurity/v1alpha1
kind: Certificate
metadata:
  name: web-tls
  namespace: shop
spec:
  issuerRef:
    name: kubeca # ClusterIssuer; kind/group fixed in v1alpha1
  profile: server-24h # default: issuer.spec.defaultProfile
  secretName: web-tls # default: metadata.name
  commonName: web.shop.svc.cluster.local
  dnsNames:
    - web.shop.svc.cluster.local
    - web.shop.svc
  ipAddresses: []
  uris:
    - spiffe://example.org/ns/shop/sa/web
  emailAddresses: []
  kubernetesNames: # optional discovery, like kubecertinit -query-k8s
    services: [web] # adds <svc>.<ns>.svc[.<domain>] and the ClusterIP
    includeUnqualified: true
    includeClusterIP: false
  duration: 24h # default: profile expiry; ≤ profile expiry and policy maxDuration
  renewBefore: 8h # default: duration / 3; must be < duration
  privateKey:
    algorithm: ECDSA # ECDSA | RSA
    size: 256 # ECDSA 256|384|521, RSA 2048|3072|4096
    rotationPolicy: Always # Always | Never
  secretTemplate:
    labels:
      app: web
    annotations: {}
status:
  conditions:
    - type: Ready
      status: "True"
      reason: Issued
      lastTransitionTime: "2026-10-06T10:00:00Z"
      observedGeneration: 2
    - type: Issuing
      status: "False"
      reason: Issued
  notBefore: "2026-10-06T09:55:00Z"
  notAfter: "2026-10-07T09:55:00Z"
  renewalTime: "2026-10-07T01:40:12Z" # notAfter − renewBefore − jitter
  serialNumber: 1F:4A:...
  issuerLabel: kubeca.svc
  issuerKeyID: 5A:3F:...
  revision: 2
  failedAttempts: 0
  lastFailureTime: null
  lastRenewRequest: ""
```

| Field                                                    | Type               | Validation (CRD / CEL)                                         | Notes                                                                                  |
| -------------------------------------------------------- | ------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `spec.issuerRef.name`                                    | string             | required                                                       | ClusterIssuer name                                                                     |
| `spec.profile`                                           | string             |                                                                | Must be exposed by the issuer, else `PolicyViolation`                                  |
| `spec.secretName`                                        | string             | DNS-1123 subdomain; immutable                                  | Default `metadata.name`                                                                |
| `spec.commonName`                                        | string             | ≤ 64 chars                                                     | Subject CN; not added to SAN automatically                                             |
| `spec.dnsNames`, `ipAddresses`, `uris`, `emailAddresses` | []string           | CEL: at least one name or `kubernetesNames.services` non-empty | Validated with `csr.ParseSAN`; duplicates dropped                                      |
| `spec.kubernetesNames.services`                          | []string           | DNS-1123 labels                                                | Services in the same namespace; a missing Service is `PolicyViolation/ServiceNotFound` |
| `spec.duration`                                          | metav1.Duration    | ≥ 10m                                                          | Bounded at reconcile by profile expiry and `maxDuration`                               |
| `spec.renewBefore`                                       | metav1.Duration    | CEL: `< duration` when both set; ≥ 5m                          |                                                                                        |
| `spec.privateKey.algorithm`                              | enum               | `ECDSA`, `RSA`                                                 | Default `ECDSA`                                                                        |
| `spec.privateKey.size`                                   | int                | CEL per algorithm                                              | Default 256 / 2048                                                                     |
| `spec.privateKey.rotationPolicy`                         | enum               | `Always`, `Never`                                              | Default `Always`                                                                       |
| `spec.secretTemplate`                                    | labels/annotations | prefix `kubeca.effectivesecurity/` reserved                    | Applied to the Secret                                                                  |

Conditions:

| Type      | Status | Reason                                                                                        | Meaning                                                                 |
| --------- | ------ | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `Ready`   | True   | `Issued`                                                                                      | The Secret holds a valid certificate matching the spec                  |
| `Ready`   | False  | `Pending`, `IssuerNotReady`, `PolicyViolation`, `IssuanceFailed`, `SecretConflict`, `Expired` | See [operator.md](operator.md), "Issuance pipeline" and "Failure modes" |
| `Issuing` | True   | `Initial`, `Renewal`, `SpecChanged`, `SecretMissing`, `CAChanged`, `Requested`                | An issuance is in progress or being retried (transient failure)         |
| `Issuing` | False  | `Issued`, `Failed`                                                                            |                                                                         |

`observedGeneration` on both conditions tracks `metadata.generation`.

Printer columns: `READY`, `SECRET`, `ISSUER`, `PROFILE`, `NOT AFTER`,
`RENEWAL`, `AGE`. Short names: `cert`, `certs`.

Annotations on the Certificate:

| Annotation                                 | Effect                                                                |
| ------------------------------------------ | --------------------------------------------------------------------- |
| `kubeca.effectivesecurity/renew-requested` | Any value different from `status.lastRenewRequest` triggers a renewal |

## Secret contract

Type `kubernetes.io/tls`, name `spec.secretName`, controller owner
reference to the Certificate (garbage-collected with it).

| Key       | Content                                                        |
| --------- | -------------------------------------------------------------- |
| `tls.crt` | Leaf certificate followed by the issuer chain, PEM             |
| `tls.key` | Private key, PEM (same encoding as `kubecertinit`'s `tls.key`) |
| `ca.crt`  | Root bundle of the issuer, PEM                                 |

| Label / annotation                                            | Value                                                                                |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| label `kubeca.effectivesecurity/managed`                      | `"true"` (cache selector)                                                            |
| annotation `kubeca.effectivesecurity/certificate`             | `<namespace>/<name>` of the Certificate                                              |
| annotation `kubeca.effectivesecurity/issuer`                  | ClusterIssuer name                                                                   |
| annotation `kubeca.effectivesecurity/profile`                 | profile                                                                              |
| annotation `kubeca.effectivesecurity/serial`                  | serial number (hex, colon-separated)                                                 |
| annotation `kubeca.effectivesecurity/not-before`, `not-after` | RFC 3339                                                                             |
| annotation `kubeca.effectivesecurity/revision`                | `status.revision` at the write                                                       |
| label `kubeca.effectivesecurity/adopt`                        | set by an operator to `"true"` to let the controller take over a pre-existing Secret |

## Pod contract

Labels select the Pods the operator watches (cache selector); annotations
carry parameters.

| Label / annotation                                             | Required | Meaning                                                                                                |
| -------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------ |
| label `kubeca.effectivesecurity/inject`                        | yes      | `"true"`: the Pod controller (and the webhook on `CREATE`) handle this Pod                             |
| annotation `kubeca.effectivesecurity/issuer`                   | yes      | ClusterIssuer name                                                                                     |
| annotation `kubeca.effectivesecurity/profile`                  | no       | profile; default the issuer's `defaultProfile`                                                         |
| annotation `kubeca.effectivesecurity/san`                      | no       | comma-separated extra names (validated by policy)                                                      |
| annotation `kubeca.effectivesecurity/secret-name`              | no       | Secret to write; default `<pod-name>-tls`; the webhook sets `kubeca-<8 chars>` for `generateName` Pods |
| annotation `kubeca.effectivesecurity/mount-path`               | no       | webhook only; default `/etc/tls`                                                                       |
| annotation `kubeca.effectivesecurity/containers`               | no       | webhook only; comma-separated container names to mount into; default all                               |
| annotation `kubeca.effectivesecurity/duration`, `renew-before` | no       | override the Certificate fields                                                                        |

The Pod controller creates a `Certificate` named after the Pod
(`<pod-name>`, or `<pod-name>-<secret suffix>` when the webhook generated
the Secret name) in the Pod's namespace, owned by the Pod, with:

- `dnsNames`: `<ip-dashed>.<ns>.pod.<domain>`, `<hostname>.<subdomain>.<ns>.svc.<domain>` when set, and `<svc>.<ns>.svc.<domain>` for every Service selecting the Pod (plus unqualified forms);
- `ipAddresses`: the Pod IP and the selecting Services' ClusterIPs (not `None`) and external IPs;
- `uris`: `spiffe://<trustDomain>/ns/<ns>/sa/<serviceAccountName>` when the issuer has a trust domain;
- the `san` annotation entries, classified by `csr.ParseSAN`.

The Certificate is updated when the Pod IP or the selecting Services
change; the Certificate controller re-issues on `SpecChanged`.

## Go types (sketch for `api/v1alpha1`)

```go
// +kubebuilder:object:root=true
// +kubebuilder:subresource:status
// +kubebuilder:resource:shortName=cert;certs
// +kubebuilder:printcolumn:name="Ready",type=string,JSONPath=`.status.conditions[?(@.type=="Ready")].status`
// +kubebuilder:printcolumn:name="Secret",type=string,JSONPath=`.spec.secretName`
// +kubebuilder:printcolumn:name="Issuer",type=string,JSONPath=`.spec.issuerRef.name`
// +kubebuilder:printcolumn:name="Profile",type=string,JSONPath=`.spec.profile`
// +kubebuilder:printcolumn:name="Not After",type=date,JSONPath=`.status.notAfter`
// +kubebuilder:printcolumn:name="Renewal",type=date,JSONPath=`.status.renewalTime`
// +kubebuilder:printcolumn:name="Age",type=date,JSONPath=`.metadata.creationTimestamp`
type Certificate struct {
	metav1.TypeMeta   `json:",inline"`
	metav1.ObjectMeta `json:"metadata,omitempty"`
	Spec              CertificateSpec   `json:"spec"`
	Status            CertificateStatus `json:"status,omitempty"`
}

// +kubebuilder:validation:XValidation:rule="(has(self.dnsNames) && size(self.dnsNames) > 0) || (has(self.ipAddresses) && size(self.ipAddresses) > 0) || (has(self.uris) && size(self.uris) > 0) || (has(self.emailAddresses) && size(self.emailAddresses) > 0) || (has(self.kubernetesNames) && has(self.kubernetesNames.services) && size(self.kubernetesNames.services) > 0)",message="at least one name is required"
// +kubebuilder:validation:XValidation:rule="!has(self.renewBefore) || !has(self.duration) || duration(self.renewBefore) < duration(self.duration)",message="renewBefore must be shorter than duration"
type CertificateSpec struct {
	IssuerRef       IssuerReference  `json:"issuerRef"`
	Profile         string           `json:"profile,omitempty"`
	SecretName      string           `json:"secretName,omitempty"`
	CommonName      string           `json:"commonName,omitempty"`
	DNSNames        []string         `json:"dnsNames,omitempty"`
	IPAddresses     []string         `json:"ipAddresses,omitempty"`
	URIs            []string         `json:"uris,omitempty"`
	EmailAddresses  []string         `json:"emailAddresses,omitempty"`
	KubernetesNames *KubernetesNames `json:"kubernetesNames,omitempty"`
	Duration        *metav1.Duration `json:"duration,omitempty"`
	RenewBefore     *metav1.Duration `json:"renewBefore,omitempty"`
	PrivateKey      *PrivateKeySpec  `json:"privateKey,omitempty"`
	SecretTemplate  *SecretTemplate  `json:"secretTemplate,omitempty"`
}

type CertificateStatus struct {
	Conditions       []metav1.Condition `json:"conditions,omitempty"`
	NotBefore        *metav1.Time       `json:"notBefore,omitempty"`
	NotAfter         *metav1.Time       `json:"notAfter,omitempty"`
	RenewalTime      *metav1.Time       `json:"renewalTime,omitempty"`
	SerialNumber     string             `json:"serialNumber,omitempty"`
	IssuerLabel      string             `json:"issuerLabel,omitempty"`
	IssuerKeyID      string             `json:"issuerKeyID,omitempty"`
	Revision         int64              `json:"revision,omitempty"`
	FailedAttempts   int32              `json:"failedAttempts,omitempty"`
	LastFailureTime  *metav1.Time       `json:"lastFailureTime,omitempty"`
	LastRenewRequest string             `json:"lastRenewRequest,omitempty"`
}

// +kubebuilder:object:root=true
// +kubebuilder:subresource:status
// +kubebuilder:resource:scope=Cluster,shortName=cissuer
type ClusterIssuer struct {
	metav1.TypeMeta   `json:",inline"`
	metav1.ObjectMeta `json:"metadata,omitempty"`
	Spec              ClusterIssuerSpec   `json:"spec"`
	Status            ClusterIssuerStatus `json:"status,omitempty"`
}

type ClusterIssuerSpec struct {
	IssuerLabel    string        `json:"issuerLabel"`
	Profiles       []string      `json:"profiles,omitempty"`
	DefaultProfile string        `json:"defaultProfile,omitempty"`
	SPIFFE         *SPIFFESpec   `json:"spiffe,omitempty"`
	Policy         *IssuerPolicy `json:"policy,omitempty"`
	CABundle       *CABundleSpec `json:"caBundle,omitempty"`
}

type IssuerPolicy struct {
	NamespaceSelector     *metav1.LabelSelector `json:"namespaceSelector,omitempty"`
	MaxDuration           *metav1.Duration      `json:"maxDuration,omitempty"`
	// Pointers keep an explicit empty list (deny the name type) distinct
	// from an absent one (allow); a plain slice with omitempty would drop it.
	AllowedDNSNames       *[]string             `json:"allowedDNSNames,omitempty"`
	AllowedURIs           *[]string             `json:"allowedURIs,omitempty"`
	AllowedEmailAddresses *[]string             `json:"allowedEmailAddresses,omitempty"`
	AllowIPAddresses      bool                  `json:"allowIPAddresses,omitempty"`
}
```

Constants for the group, labels, annotations, condition types and reasons
live in `api/v1alpha1/constants.go` and are the only place they are
spelled out.
