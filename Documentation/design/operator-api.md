# KubeCA Operator API

Status: implemented, `kubeca.effectivesecurity/v1alpha1` (D-1). Go types
are in `api/v1alpha1/` with kubebuilder markers; CRDs are generated by
`controller-gen` (`make manifests`) into `config/crd/bases/` and copied to
`examples/kubeca/crds/`. Architecture: [operator.md](operator.md).

Naming rules: labels and annotations use the group as prefix; condition
types are `Ready` and `Issuing`; reasons are CamelCase and listed below;
Secret keys follow `kubernetes.io/tls` plus `ca.crt`. Every constant is
spelled out once in `api/v1alpha1/constants.go`.

## ClusterIssuer

Cluster-scoped. Binds an xpki issuer (loaded from the CA configuration at
start-up) to a policy and publishes its CA.

```yaml
apiVersion: kubeca.effectivesecurity/v1alpha1
kind: ClusterIssuer
metadata:
  name: kubeca
spec:
  # Issuer label in ca-config (authority.issuers[].label). Required, immutable.
  issuerLabel: kubeca.svc
  # Profiles this ClusterIssuer exposes. Empty: every profile the issuer serves.
  profiles: [peer-24h, server-24h, client-24h]
  # Used when a Certificate or a Pod omits the profile.
  defaultProfile: peer-24h
  spiffe:
    # Pod-flow URIs: spiffe://<trustDomain>/ns/<namespace>/sa/<serviceaccount>
    trustDomain: example.org
  policy:
    # Namespaces whose Certificates may use this issuer. Absent: all.
    namespaceSelector:
      matchLabels:
        kubeca.effectivesecurity/enabled: "true"
    # Upper bound for Certificate.spec.duration; also bounded by the profile expiry.
    maxDuration: 24h
    # Regexes; ${NAMESPACE}, ${NAME}, ${SERVICE_ACCOUNT}, ${CLUSTER_DOMAIN} are
    # substituted (regex-quoted). ${SERVICE_ACCOUNT} is the ServiceAccount of the
    # Pod whose Certificate this is (Pod flow); empty for a Certificate no Pod owns.
    # ${CLUSTER_DOMAIN} is the operator's -cluster-domain, the suffix of the names
    # it derives. spec.commonName must match allowedDNSNames as well.
    allowedDNSNames:
      - ^[a-z0-9-]+\.${NAMESPACE}\.svc(\.${CLUSTER_DOMAIN})?$
      - ^[a-z0-9-]+\.[a-z0-9-]+\.${NAMESPACE}\.svc(\.${CLUSTER_DOMAIN})?$
      # one wildcard label over a headless Service (StatefulSet Pod names)
      - ^\*\.[a-z0-9-]+\.${NAMESPACE}\.svc(\.${CLUSTER_DOMAIN})?$
      - ^[0-9a-f-]+\.${NAMESPACE}\.pod\.${CLUSTER_DOMAIN}$ # IPv4 and IPv6 Pod names
      - ^localhost$
    allowedURIs:
      - ^spiffe://example\.org/ns/${NAMESPACE}/sa/[a-z0-9-]+$
    allowedEmailAddresses: []
    allowIPAddresses: true
  caBundle:
    # Optional: publish ca.crt into this ConfigMap in every namespace that has a Certificate of this issuer.
    configMapName: kubeca-ca
status:
  conditions:
    - type: Ready
      status: "True"
      reason: Loaded
      message: issuer kubeca.svc, 3 profiles
      lastTransitionTime: "2026-10-06T10:00:00Z"
      observedGeneration: 1
  issuerKeyID: 5a3f... # SKID of the issuing certificate, hex
  caCertificate: | # issuing certificate + chain, PEM
    -----BEGIN CERTIFICATE-----
  rootCertificate: | # root bundle, PEM (what goes into ca.crt)
    -----BEGIN CERTIFICATE-----
  caNotAfter: "2031-10-06T00:00:00Z"
  profiles: # sorted by name
    - name: client-24h
      expiry: 24h0m0s
      backdate: 5m0s
      usages: [signing, key encipherment, client auth]
```

| Field                                                                 | Type                 | Validation                                   | Notes                                                                                                                                                                                                                |
| --------------------------------------------------------------------- | -------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `spec.issuerLabel`                                                    | string               | required, immutable (CEL `self == oldSelf`)  | Must exist in the running Authority; otherwise `Ready=False/IssuerNotFound`                                                                                                                                          |
| `spec.profiles`                                                       | []string             | each must be served by the issuer            | Unknown entries → `Ready=False/ProfileNotFound`                                                                                                                                                                      |
| `spec.defaultProfile`                                                 | string               | CEL: in `profiles` when both set; served     | Unknown → `Ready=False/ProfileNotFound`                                                                                                                                                                              |
| `spec.spiffe.trustDomain`                                             | string               | DNS name                                     | Enables the SPIFFE URI in the Pod flow                                                                                                                                                                               |
| `spec.policy.namespaceSelector`                                       | metav1.LabelSelector | valid selector (else `InvalidPolicy`)        | nil = all namespaces                                                                                                                                                                                                 |
| `spec.policy.maxDuration`                                             | metav1.Duration      | ≥ 1m                                         |                                                                                                                                                                                                                      |
| `spec.policy.allowedDNSNames`, `allowedURIs`, `allowedEmailAddresses` | \*[]string           | valid RE2 after substitution (else `InvalidPolicy`) | Empty list = that name type is denied; absent = allowed (a pointer in Go, so a client's explicit `[]` is not dropped by `omitempty`). A wildcard name is allowed only by an expression that matches the leading `*.` |
| `spec.policy.allowIPAddresses`                                        | bool                 |                                              | default false                                                                                                                                                                                                        |
| `spec.caBundle.configMapName`                                         | string               | DNS-1123 subdomain                           | The ConfigMaps are owned by the ClusterIssuer, labeled `managed=true`, key `ca.crt`; a ConfigMap of that name controlled by anything else, another ClusterIssuer with the same name included, or neither owned nor labeled, is left alone with a `ConfigMapConflict` event. The issuer deletes the ones it owns in a namespace without one of its Certificates, under a previous name, or all of them when `caBundle` is removed |

Conditions: `Ready` with reasons `Loaded` and `CAExpiring` (status
`True`; `CAExpiring` means CA `NotAfter` < now + the longest lifetime
the issuer can sign, the longest exposed expiry or `maxDuration` when
that is shorter, so issued certificates are clipped) and
`IssuerNotFound`, `ProfileNotFound`, `InvalidPolicy`, `CAExpired` (status
`False`). A transition is also an event with the reason (`Ready` for
`Loaded`).

Printer columns: `READY`, `LABEL` (`spec.issuerLabel`), `CA NOT AFTER`
(RFC 3339 string), `AGE`. Short name: `cissuer`.

## Certificate

Namespaced. Describes one certificate and the Secret that holds it.

```yaml
apiVersion: kubeca.effectivesecurity/v1alpha1
kind: Certificate
metadata:
  name: web-tls
  namespace: shop
spec:
  issuerRef:
    name: kubeca # ClusterIssuer; kind/group fixed in v1alpha1
  profile: server-24h # default: issuer.spec.defaultProfile
  secretName: web-tls # default: metadata.name; immutable
  commonName: web.shop.svc.cluster.local
  dnsNames:
    - web.shop.svc.cluster.local
    - web.shop.svc
  ipAddresses: []
  uris:
    - spiffe://example.org/ns/shop/sa/web
  emailAddresses: []
  kubernetesNames: # optional discovery, like kubecertinit -service-names
    services: [web] # adds <svc>.<ns>.svc.<domain>
    includeUnqualified: true # and <svc>.<ns>.svc
    includeClusterIP: false # and the cluster addresses (both families of a dual-stack Service) as IP SANs
  duration: 24h # default: profile expiry; ≤ profile expiry and policy maxDuration
  renewBefore: 8h # default: duration / 3; must be < duration
  privateKey:
    algorithm: ECDSA # ECDSA | RSA
    size: 256 # ECDSA 256|384|521, RSA 2048|3072|4096
    rotationPolicy: Always # Always | Never
  secretTemplate:
    labels:
      app: web
    annotations: {}
status:
  conditions:
    - type: Ready
      status: "True"
      reason: Issued
      message: certificate 1F:4A:... valid until 2026-10-07T09:55:00Z
      lastTransitionTime: "2026-10-06T10:00:00Z"
      observedGeneration: 2
    - type: Issuing
      status: "False"
      reason: Issued
  notBefore: "2026-10-06T09:55:00Z"
  notAfter: "2026-10-07T09:55:00Z"
  renewalTime: "2026-10-07T01:40:12Z" # notAfter − renewBefore − jitter
  serialNumber: 1F:4A:...
  issuerLabel: kubeca.svc
  issuerKeyID: 5a3f...
  revision: 2
  failedAttempts: 0
  lastFailureTime: null
  lastRenewRequest: ""
```

| Field                                                    | Type               | Validation (CRD / CEL)                                         | Notes                                                                                                                 |
| -------------------------------------------------------- | ------------------ | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `spec.issuerRef.name`                                    | string             | required                                                       | ClusterIssuer name                                                                                                    |
| `spec.profile`                                           | string             |                                                                | Must be exposed by the ClusterIssuer and served by the issuer, else `PolicyViolation`                                 |
| `spec.secretName`                                        | string             | DNS-1123 subdomain; immutable                                  | Default `metadata.name`                                                                                               |
| `spec.commonName`                                        | string             | ≤ 64 chars                                                     | Subject CN; not added to SAN automatically; must match the policy's `allowedDNSNames` when that list is set           |
| `spec.dnsNames`, `ipAddresses`, `uris`, `emailAddresses` | []string           | CEL: at least one name or `kubernetesNames.services` non-empty | Validated with `csr.ParseSAN`; duplicates dropped; the profile must copy each name type present (`allowed_fields`)    |
| `spec.kubernetesNames.services`                          | []string           | DNS-1123 labels                                                | Services in the same namespace; a missing Service is `PolicyViolation` (`ServiceNotFound`), retried when it appears; `includeClusterIP` adds `spec.clusterIPs` (both families) |
| `spec.duration`                                          | metav1.Duration    | ≥ 1m                                                           | Bounded at reconcile by profile expiry and `maxDuration`; must leave ≥ 2m after the profile backdate (`PolicyViolation`) |
| `spec.renewBefore`                                       | metav1.Duration    | CEL: `< duration` when both set; ≥ 30s                         | Falls back to a third of the actual lifetime when not shorter than it; applied in place on change                      |
| `spec.privateKey.algorithm`                              | enum               | `ECDSA`, `RSA`                                                 | Default `ECDSA`                                                                                                       |
| `spec.privateKey.size`                                   | int                | CEL per algorithm                                              | Default 256 / 2048                                                                                                    |
| `spec.privateKey.rotationPolicy`                         | enum               | `Always`, `Never`                                              | Default `Always`                                                                                                      |
| `spec.secretTemplate`                                    | labels/annotations | prefix `kubeca.effectivesecurity/` reserved (ignored)          | Applied to the Secret, also in place; an invalid key or value is `PolicyViolation` before signing                     |

Conditions:

| Type      | Status | Reason                                                                             | Meaning                                                                 |
| --------- | ------ | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `Ready`   | True   | `Issued`                                                                           | The Secret holds a valid certificate matching the spec                  |
| `Ready`   | False  | `IssuerNotReady`, `PolicyViolation`, `IssuanceFailed`, `SecretConflict`            | See [operator.md](operator.md), "Issuance pipeline" and "Failure modes"; `IssuerNotReady` leaves `Ready=True` while the stored certificate is valid |
| `Issuing` | True   | `Initial`, `Renewal`, `SpecChanged`, `SecretMissing`, `CAChanged`, `Requested`     | An issuance is in progress or being retried (transient failure)         |
| `Issuing` | False  | `Issued`, `Failed`                                                                 |                                                                         |

`observedGeneration` on both conditions tracks `metadata.generation`.
Every `Ready=False` reason is also a `Warning` event with that reason;
`Issued` and `Renewed` are `Normal` events.

Printer columns: `READY`, `SECRET`, `ISSUER`, `PROFILE`, `NOT AFTER`,
`RENEWAL` (both RFC 3339 strings: kubectl renders a future time of a
`date` column as `<invalid>`), `AGE`. Short names: `cert`, `certs`.

Annotations on the Certificate:

| Annotation                                 | Effect                                                                |
| ------------------------------------------ | --------------------------------------------------------------------- |
| `kubeca.effectivesecurity/renew-requested` | Any value different from `status.lastRenewRequest` triggers a renewal; removing the annotation after a request is a change too: one renewal, which clears `status.lastRenewRequest` |

The policy placeholder `${SERVICE_ACCOUNT}` is never read from the
Certificate: it is the ServiceAccount of the Pod that controls the
Certificate, and only when the Certificate is exactly the one the Pod
controller writes for that Pod: the owner reference carries the Pod's
UID, and the name, `secretName` and issuer are `PodCertificateName`,
`PodSecretName` (in `api/v1alpha1`) and the Pod's `issuer` annotation.
Anything else, whatever its annotations, expands it to the empty string,
so a policy that uses it denies the request.

Owner references are written by whoever creates the object. The chart's
`ValidatingAdmissionPolicy` `<fullname>-pod-certificates` (Kubernetes 1.30
or later, `operator.podCertificatePolicy`) therefore denies the creation
of a Certificate controlled by a Pod, and any change of its spec or owner
references, to everyone but the operator's ServiceAccount; others may
still annotate it or drop the Pod as controller in an update that keeps
the spec (it then is a plain Certificate, for which `${SERVICE_ACCOUNT}`
expands to the empty string). Without the policy, an author who copies a Pod's UID gets
that Pod's identity written into the Pod's own Secret only, which nobody
can read who cannot already read that Secret.

## Secret contract

Type `kubernetes.io/tls`, name `spec.secretName`, controller owner
reference to the Certificate (garbage-collected with it). The type is set
on creation; an existing Secret of another type is a `SecretConflict`
before any issuance or adoption (the type is immutable).

While the certificate is up to date, the controller keeps the parts that
do not depend on the issuance as an issuance would write them today: the
issuer chain after the leaf in `tls.crt` and `ca.crt`. A removed or
replaced chain or bundle is restored in place, without a re-issuance.

| Key       | Content                                                        |
| --------- | -------------------------------------------------------------- |
| `tls.crt` | Leaf certificate followed by the issuer chain, PEM             |
| `tls.key` | Private key, PEM (`EC PRIVATE KEY` / `RSA PRIVATE KEY`, same encoding as `kubecertinit`'s `tls.key`) |
| `ca.crt`  | Root bundle of the issuer, PEM (`ClusterIssuer.status.rootCertificate`) |

| Label / annotation                                            | Value                                                                                |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| label `kubeca.effectivesecurity/managed`                      | `"true"` (cache selector)                                                            |
| annotation `kubeca.effectivesecurity/certificate`             | `<namespace>/<name>` of the Certificate                                              |
| annotation `kubeca.effectivesecurity/issuer`                  | ClusterIssuer name                                                                   |
| annotation `kubeca.effectivesecurity/profile`                 | profile                                                                              |
| annotation `kubeca.effectivesecurity/serial`                  | serial number (upper-case hex, colon-separated)                                      |
| annotation `kubeca.effectivesecurity/not-before`, `not-after` | RFC 3339                                                                             |
| annotation `kubeca.effectivesecurity/issued-at`               | RFC 3339 time of the issuance; the renewal is never scheduled within a minute of it  |
| annotation `kubeca.effectivesecurity/duration`                | the lifetime that was requested (bounded by the profile and the policy); a different effective duration re-issues (`SpecChanged`), the leaf validity is not compared because the issuer may clip it |
| annotation `kubeca.effectivesecurity/revision`                | `status.revision` at the write                                                       |
| annotation `kubeca.effectivesecurity/renew-requested`         | the Certificate's `renew-requested` value this issuance honoured; absent when there was none. When the status write after an issuance fails, the next reconcile takes `status.revision` and `status.lastRenewRequest` from `revision` and this annotation, so the issuance is neither counted nor repeated |
| label `kubeca.effectivesecurity/adopt`                        | set by an operator to `"true"` to let the controller take over a pre-existing Secret |

A Secret controlled by a Certificate of the same name that no longer
exists is adopted by a re-created Certificate; one controlled by anything
else, or unmanaged and unlabeled, is a `SecretConflict`.

## Pod contract

Labels select the Pods the operator watches (cache selector); annotations
carry parameters.

| Label / annotation                                             | Required | Meaning                                                                                                                      |
| -------------------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| label `kubeca.effectivesecurity/inject`                        | yes      | `"true"`: the Pod controller (and the webhook on `CREATE`) handle this Pod                                                   |
| annotation `kubeca.effectivesecurity/issuer`                   | yes      | ClusterIssuer name (an `InvalidPod` event without it)                                                                        |
| annotation `kubeca.effectivesecurity/profile`                  | no       | profile; default the issuer's `defaultProfile`                                                                               |
| annotation `kubeca.effectivesecurity/san`                      | no       | comma-separated extra names (validated by `csr.ParseSAN` and the policy)                                                     |
| annotation `kubeca.effectivesecurity/secret-name`              | no       | Secret to write; default `<pod-name>-tls`; the webhook sets it (`<name>-tls`, or `kubeca-<8 chars>` for `generateName` Pods) |
| annotation `kubeca.effectivesecurity/mount-path`               | no       | webhook only; default `/etc/tls`                                                                                             |
| annotation `kubeca.effectivesecurity/containers`               | no       | webhook only; comma-separated container names to mount into; default all                                                    |
| annotation `kubeca.effectivesecurity/duration`, `renew-before` | no       | override the Certificate fields (Go durations; an invalid value is an `InvalidPod` event)                                     |

The Pod controller creates a `Certificate` in the Pod's namespace, owned
by the Pod, named after the Pod when the `secret-name` annotation is
absent or equals `<pod-name>-tls`, and `<pod-name>-<last dash-separated
segment of the annotation>` otherwise (`<pod-name>-<8 chars>` for a
webhook-generated name), with:

- `dnsNames`: `<ip-dashed>.<ns>.pod.<domain>`, `<hostname>.<subdomain>.<ns>.svc.<domain>` when set, and `<svc>.<ns>.svc.<domain>` for every Service selecting the Pod, each also in the unqualified `.svc` form;
- `ipAddresses`: every Pod address (`status.podIPs`, both families of a dual-stack Pod) and the selecting Services' cluster addresses (`spec.clusterIPs`, both families; not `None`) and external IPs; a Service with no selector, or an empty one, selects nothing;
- `uris`: `spiffe://<trustDomain>/ns/<ns>/sa/<serviceAccountName>` when the issuer has a trust domain;
- the `san` annotation entries, classified by `csr.ParseSAN`;
- `secretName`, `profile`, `duration`, `renewBefore` from the annotations.

The Certificate is updated when the Pod IP, the selecting Services or the
issuer's trust domain change; the Certificate controller re-issues on
`SpecChanged`. A Pod needs at least one name source that does not depend
on its IP (a selecting Service, `hostname`/`subdomain`, the `san`
annotation or a trust domain on the issuer): the kubelet mounts the
injected Secret volume before it creates the Pod sandbox, so a Pod with
no other name never gets the IP that would name it. Such a Pod gets an
`InvalidPod` event saying what is missing. An existing Certificate of
that name that this Pod does not control (no controller, another
controller, or a previous Pod of the same name, which is retried until
the garbage collector deletes it) is never written or adopted; it is an
`InvalidPod` event too. The owner
references the controllers set carry `blockOwnerDeletion: false`, so no
`*/finalizers` permission is needed under the
`OwnerReferencesPermissionEnforcement` admission plugin.

The webhook mutates a labeled Pod on `CREATE` only: it records the Secret
name, adds a Secret volume `kubeca-tls` unless a volume already references
the Secret (the name gets a `-1`, `-2`... suffix when taken), and mounts it
read-only at the mount path into the selected containers that have no
mount at that path. It never rejects a Pod; a Pod it cannot decode is a
400.

## Go types

The sketch of the proposal became `api/v1alpha1/certificate_types.go` and
`clusterissuer_types.go`; read them for the markers. Highlights:

- `Certificate` and `ClusterIssuer` have the status subresource; the
  controllers patch status with `client.MergeFrom`.
- `IssuerPolicy.Allowed*` are `*[]string` (an explicit empty list denies
  the type).
- Helpers: `Certificate.SecretNameOrDefault`, `KeyAlgorithmOrDefault`,
  `RotationPolicyOrDefault`; `ClusterIssuer.TrustDomain`, `ExposesProfile`.
- CEL rules: at least one name; `renewBefore < duration`; `duration ≥ 1m`;
  `renewBefore ≥ 30s`; `maxDuration ≥ 1m`; `privateKey.size` per
  algorithm; `secretName` (once set it can neither change nor be removed)
  and `issuerLabel` immutable; `defaultProfile` in `profiles`.
- Printer columns of type `string` for the timestamps.

Constants for the group, labels, annotations, condition types, reasons,
event reasons, Secret keys and defaults live in
`api/v1alpha1/constants.go` and are the only place they are spelled out.
